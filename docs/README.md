# Documentation

This directory contains all project documentation, organized into logical sections.

## Structure

### `/plans/` - Project Planning
- `01_PROJECT_OVERVIEW.md` - High-level project overview
- `02_FRONTEND_PLAN.md` - Frontend architecture and planning
- `03_BACKEND_PLAN.md` - Backend architecture and planning
- `04_TEST_STRATEGY.md` - Testing strategy and approach
- `05_E2E_SCENARIOS.md` - End-to-end test scenarios

### `/setup/` - Setup & Configuration Guides
- `DEEPGRAM_QUICK_REFERENCE.md` - Quick reference for Deepgram integration
- `DEEPGRAM_VIETNAMESE_SETUP.md` - Vietnamese-specific Deepgram setup

### `/assets/` - Media & Resources
- Audio files used for testing and samples
- Images and other media assets

### Root Level
- `WORKLOG_2026-05-25.md` - Project worklog and notes
- `GEMINI.md` - Gemini integration notes (in root)

## How to Use

1. Start with `plans/01_PROJECT_OVERVIEW.md` for project context
2. Check `setup/` for integration guides
3. Review relevant plan docs for your area of work
